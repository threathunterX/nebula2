## 计划内容

按接入方式分章,每种给出完整可运行示例:

1. **旁路镜像流量**(Zeek):适用场景、网卡配置、性能调优
2. **Nginx 日志**:OpenResty Lua 直采到 Kafka,接入成本最低
3. **Kafka**:消费业务方已有的日志流,字段映射配置
4. **syslog / 文件**:传统日志接入
5. **SDK 埋点**:需要业务字段(订单金额、支付方式)时的上报方式
6. **`/checkRisk` 同步查询**:业务系统如何在登录/下单/支付前查询风险结论

另含:字段映射与事件归类、脱敏规则配置、接入后的验证方法
