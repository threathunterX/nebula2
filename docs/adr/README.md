# 架构决策记录(ADR)

记录关键技术决策及其背后的推理。重点不是"我们用了什么",而是**"为什么"以及"放弃了什么"**——这样后来者在情况变化时能判断决策是否仍然成立。

| [0005](0005-schema-single-source-of-truth.md) | 领域模型以 JSON Schema 为单一真相源 | 已接受 |

## 写作约定

每条 ADR 包含:背景(当时面临什么问题)、决策(做了什么)、理由(为什么这样选)、代价(放弃了什么、引入了什么新问题)、后果(对其他部分的影响)。

决策被推翻时不删除原记录,而是新增一条并把旧条目标记为"已废弃",注明被哪条取代。
