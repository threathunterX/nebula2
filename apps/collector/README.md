# collector —— 数据采集器

🚧 实现中。

Go 编写的单二进制采集器。负责把各种来源的业务流量与日志,还原成标准化的事件,并**在数据离开客户网络边界前完成敏感字段脱敏**。

## 计划支持的数据源

| 驱动 | 说明 |
|---|---|
| `kafka` | 消费业务方已有的日志流 |
| `syslog` | 接收 syslog(UDP/TCP) |
| `file` | 尾随日志文件 |
| `http` | 接收 SDK 埋点上报 |
| `nginx-lua` | 配套 OpenResty 脚本从 Nginx 层直采 |
| `zeek` | 旁路镜像流量,Zeek 作为外部进程 |

1.x 的 tshark HTTPS 解密驱动不再提供——密钥管理风险高,且现代 TLS 配置下基本不可行。

## 为什么用 Go

采集器是长驻网络服务,需要部署到客户环境。Go 的单二进制、无运行时依赖、交叉编译与可控内存占用,对私有化部署是实际优势:运维只需要拷贝一个文件。

## 脱敏

脱敏在采集器内完成,是隐私设计的第一道也是最重要的一道关口。规则与默认值见[隐私设计](../../docs/security/privacy.md)。
